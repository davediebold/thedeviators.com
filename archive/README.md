These files preserve the project's history and original deliverables. They are not the current editing, preview, or deployment instructions. Use the root `README.md` and `AGENTS.md` instead.

- `site-build/`: former build folder, preserved with its original internal structure. Its documentation includes obsolete Netlify hosting instructions, old paths, and resolved content tasks. Its generator is a historical reference, not a supported command for the current website.
- `original-deliverables/deviators-site-build.zip`: original ZIP, formerly in `Claude outputs/`.
- `planning/Website Improvement Plan.md`: initial plan written before the current site was deployed.

Do not follow archived instructions to change hosting, DNS, credentials, or publication status. Do not run the archived generator: its relative paths no longer represent the current project layout. Do not delete originals merely because the same material is also included in the ZIP or published website.

The site is maintained directly in `../docs/` and deployed using GitHub Actions. Every relocated historical file was checked against its SHA-256 hash during the reorganisation on 19 September 2026.
